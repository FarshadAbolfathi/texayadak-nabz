# تکسایدک نبض

برنامهٔ دسکتاپ ویندوزی برای همگام‌سازی **قیمت** و **موجودی** بین:

- **ایساکو** (سامانهٔ B2B — منبع قیمت)
- **حاسب** (نرم‌افزار حسابداری — منبع موجودی)
- **فروشگاه تکسایدک** (ووکامرس — مقصد)

## قابلیت‌ها

- سینک قیمت از لیست ایساکو با درصد سود قابل تنظیم، تبدیل ریال↔تومان و رند کردن
- سینک موجودی از دیتابیس حاسب (DBF) با **سقف موجودی** قابل تنظیم
- ایمپورت اکسل/CSV حسابداری با نگاشت ستون
- مدیریت و ویرایش دستی محصولات سایت + خروجی اکسل
- **رول‌بک**: بازگرداندن هر اجرا به حالت قبل
- محافظ‌ها: علامت‌گذاری تغییرات بزرگ برای بررسی دستی، اعتبارسنجی فایل ایساکو
- زمان‌بندی خودکار روزانه + جبران اجرای از دست رفته + System Tray
- **چند زمان‌بندی در روز**؛ هر ساعت می‌تواند فقط قیمت، فقط موجودی یا هر دو را سینک کند
- **محصولات جدید حاسب**: کشف کالاهای موجود در حاسب که روی سایت نیستند، با قیمت و
  دستهٔ پیشنهادی، و ساخت روی سایت فقط با تأیید کارفرما (هرگز خودکار)
- **دسته‌بندی خودکار**: تطبیق نام محصول و «مصرف خودرو» ایساکو با نام دسته‌های سایت
  (سپر عقب ۴۰۵ → پژو ۴۰۵) + قواعد دستی «کلمه → دسته»
- **مدیریت کامل محصولات سایت**: ویرایش همهٔ ستون‌ها، تصویر شاخص، دسته‌ها، ویرایش
  گروهی، افزودن و حذف
- **سفارش‌ها**: مشاهده، تغییر وضعیت، یادداشت، چاپ فاکتور و PDF
- **تاریخ شمسی** در همهٔ بخش‌ها (گزارش‌ها، سفارش‌ها، فاکتور، لاگ)
- رمز ورود به برنامه، ذخیرهٔ رمزنگاری‌شدهٔ اعتبارنامه‌ها (DPAPI ویندوز)
- رابط کاربری فارسی راست‌به‌چپ با تب راهنما و پشتیبانی

## اجرا (توسعه)

```bash
python3.12 -m venv .venv
source .venv/bin/activate        # ویندوز: .venv\Scripts\activate
pip install -e .
python run_app.py
```

## تست

```bash
pip install pytest
QT_QPA_PLATFORM=offscreen pytest -q
```

## ساخت فایل نصبی ویندوز

به‌صورت خودکار با **GitHub Actions** (تب Actions → آخرین اجرا → دانلود Artifact)،
یا دستی طبق [packaging/BUILD.md](packaging/BUILD.md).

## ساختار

```
src/nabz/
├── skucode, pricing, stock, engine     منطق تطبیق و محاسبه
├── new_products, categorize            محصولات جدید حاسب و دسته‌بندی خودکار
├── invoice, jalali                      فاکتور فروش و تاریخ شمسی
├── db, config, runner, scheduler, jobs  حالت، رول‌بک، اتوماسیون
├── sources/   ایساکو (اکسل/وب/کریپتو)، حاسب (DBF)، اکسل حسابداری
├── targets/   ووکامرس (محصولات، دسته‌ها، سفارش‌ها، رسانه)
└── ui/        رابط PySide6 (۱۲ تب)
```
